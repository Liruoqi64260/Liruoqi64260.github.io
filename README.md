# Data Science Portfolio — GitHub Pages site

Static portfolio for CISC7204, authored by Ruoqi Li (mc64260).

## Overview

This repository contains the source of a framework-free GitHub Pages site. It is
plain HTML + CSS and needs no build step: GitHub Pages serves `index.html` directly
from the root of the `main` branch.

```
.
├── index.html               # Single-page portfolio (all required sections)
├── styles.css               # Minimal responsive stylesheet
└── assets/img/              # Eight figures generated by the project repository
```

## Local preview

Open `index.html` directly in a browser, or serve the folder locally:

```bash
python -m http.server 8000
# visit http://localhost:8000
```

## Deployment

1. Push this folder to a public repository named `Liruoqi64260.github.io` on branch `main`.
2. In the repository: **Settings → Pages → Build and deployment**.
3. Source = **Deploy from a branch**, Branch = **main**, folder = **/ (root)** → **Save**.
4. After 1–2 minutes the site is live at `https://Liruoqi64260.github.io/`.
